# 命名规范

目标是让 **Jellyfin / Emby / Plex / Kodi / 夸克 TV 端**都能按 `SxxExx` 命中 TMDB 条目、正确刮削。

## 目录

```
剧集：剧名 (首播年份)/Season NN/剧名 - SxxEyy - 集标题.ext
电影：片名 (年份)/片名 (年份).ext
```

- 年份取 **TMDB 的首播年**，不是资源标题里的年份。
- 特辑进 `Season 00`。
- 电影**没有 Season 层**，也不需要 `SxxExx`。

## 文件

```
Bluey (2018)/Season 02/Bluey - S02E07 - The Quiet Game.mkv
Dune (2021)/Dune (2021).mkv
```

- **连字符两侧各一个空格**：` - `。
- **集号位数**：默认两位（`E07`）。部分老资源用三位（`S01E001`）。**改前先确认目标刮削器吃哪种** —— 有些对位数敏感。
- 文件名自带 `SxxExx` 后，不**强制**再建 `Season NN` 子目录（省一次搬移）；但媒体服务器按季分组时，Season 目录更规范。

## 双集连播文件（一个文件装两集）

资源常见「每个文件 23 分钟、含 2 集」，源文件名可能写成 `第1季 第01集 第02集.mp4` 或 `第10季 第45-46集.mp4`。

**命名**：
```
剧名 - S01E01-E02 - 标题1 & 标题2.mkv
```
- 两标题之间用 **` & `**，**不要用半角逗号** —— 逗号是 Jellyfin/Emby 的保留字符，实测 Emby 用逗号分隔时只显示第一个标题。
- 解析要**同时吃两种源写法**：
  - `第(\d+)季\s+第(\d+)(?:-(\d+))?集` （区间式）
  - `第(\d+)季\s+第(\d+)集\s+第(\d+)集` （并列式）
- **判断是否双集，可靠依据是时长**（23 分钟 ≈ 2 段），**不是**文件名里的集号个数 —— 有些文件只标 1 个集号但时长仍是 23 分钟。

**格式合规，但呈现方式四家不同 —— 别向用户承诺「会像两集一样」**：

| 客户端 | 条目数 | 第二集标题 | 播放行为 |
|---|---|---|---|
| Plex | 2 个条目 | 各自显示 TMDB 标题 | 播任一条目都播整段；两集**同时**标记已看 |
| Jellyfin | **1 个条目**（官方原话：a single entry containing metadata from multiple episodes） | 合并 | 播整段 |
| Emby | 1 个条目 | **只保留第一集标题** | 播整段 |
| Kodi | 按集号分别入库 | 看皮肤 | 播整段 |

- Plex 与 Jellyfin 官方文档都写明**「想要完整体验请拆分文件」**。多集文件天然做不到「E01 只播 E01」、进度也无法分开。
- 网盘素材拆分 = 下载 → 切割 → 重传，成本极高，**一般不做**，如实说明即可。
- 提供实测指令：让用户建一个只含 1~3 个双集文件的**测试媒体库**，看列出 1 条还是 2 条，再决定是否全量。

## 特辑 / 迷你剧 / 联动

- 特辑 → `Season 00`。
- 迷你剧、跨剧联动在 TMDB 常是**独立条目**，**单独建目录**，不要塞进母剧某一季。
- 同一批短片可能**同时出现在两个条目下**（挂在母剧特辑里又挂在迷你剧里），报缺口时要说清是同一批内容。

## 文件名字符处理

多数批量改名接口会卡这些字符，先本地清洗：

| 原字符 | 处理 | 例 |
|---|---|---|
| `:` | → ` -` | `Fire Rescue: Pups` → `Fire Rescue - Pups` |
| `?` | → `？`（全角） | `Where's Bingo?` → `Where's Bingo？` |
| `,` | → 空格 | `Rocky, the Cat` → `Rocky the Cat` |
| `%` | → 空格 | `100% Fun` → `100 Fun` |
| `\ / * " < > \|` | 删除 | — |
| 连续多空格 | 合并为一个 | — |

另有 `length ≤ 255` 的硬限制。

## 常见非问题（不要改）

- **客户端显示的集标题与文件名不一致** —— 正常。客户端显示的是 TMDB 的标题，文件名只是用来定位。措辞差异（`- featuring X` vs `(Finny the Shark)`）不影响。
- **同步工具把撇号变成逗号**（`Carl's` → `Carl,s`）—— 不影响刮削。
- **集合本身缺集**时，客户端显示缺号属正常，**不要用后续集号补位**。

## 验证（改完必做）

```bash
# 用脚本校验一份文件名清单是否合规（字符集 / 长度 / 同目录重名 / 与剧名匹配）
node scripts/validate-names.mjs --files names.txt --show "<剧名>"
```

人工回读三条：
1. 文件名全部符合 `^<剧名> - S\d{2}E\d{2}(-E\d{2})? - .+\.\w+$`；
2. 集号无重复；
3. 集号无空洞（若有，须能解释，见 [pitfalls.md](pitfalls.md)）。
